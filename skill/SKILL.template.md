# 네이버 블로그 글 작성

**발행은 절대 하지 않는다.** 글 작성 → 파일 저장 → 에디터 입력(또는 클립보드 복사)까지만.

> 이 파일은 `pnpm init-skill` 로 생성된 **내 블로그 전용 스킬**입니다. `블로그 프로필`·`문체`는 내 블로그에 맞게 자유롭게 고치세요.

## 입력
`/naver-blog <주제> [키워드: a,b] [톤: 친근|정보|후기] [분량: 1500자]`
누락된 항목은 질문하지 말고 아래 기본값으로 진행.

## 블로그 프로필 (blog.naver.com/{{BLOG_ID}})
- 블로그명: {{BLOG_NAME}} / 소개: {{BLOG_TAGLINE}}
- 운영자·주제: {{BLOG_PROFILE}}
- 카테고리: {{BLOG_CATEGORIES}}
- 제목 패턴: {{BLOG_TITLE_PATTERN}}
- 문체: {{BLOG_TONE}}. 요청에 따로 없으면 카테고리로 판단.
- 정보 글 구조: 도입(왜 필요한지) → "OO란?" → 단계별 방법/조건 → 내 경험/팁 → 주의사항.
- 방문 후기 구조: 위치·주차·영업시간 → 분위기 → 메뉴·가격 → 맛/총평 → 이런 사람에게 추천. 영업시간·가격·주소는 모르면 `[확인 필요]`, 직접 겪은 감상은 `[내 경험 추가]`.

## 기본값
- 톤: 위 문체 규칙 따름. AI 티 나는 상투구 금지: "오늘은 ~에 대해 알아보겠습니다", "결론적으로" 남발 등
- 분량: 1,500~2,500자
- 메인 키워드: 주제에서 추출, 제목 앞쪽 + 첫 문단 + 소제목 1~2곳 + 마지막 문단에 자연스럽게 (과다 반복 금지)

## 키워드 단계 (글 쓰기 전)
1. 주제에서 시드 키워드 3~5개를 뽑는다 (지역+서비스+의도 롱테일 위주).
2. `.env` 에 검색광고 API 키가 있으면 `pnpm keywords "시드1" "시드2"` 로 월간 검색수·경쟁도를 조회해 메인 1 + 보조 2~3개를 고른다. 키가 없으면 후보만 제시하고 검색수는 지어내지 않는다 (`[확인 필요: 검색량]`).
3. 상위 노출 글이 대형 업체 글뿐인 키워드(경쟁 강함)보다 개인 후기가 상위인 키워드를 우선.
4. 메인 키워드는 제목 앞쪽·첫 문단·소제목 1~2곳·마무리·태그에, 보조 키워드는 소제목/본문에 자연스럽게. 응답에 선택한 키워드와 이유를 한 줄로.
5. 발행 1~2주 후 블로그 통계의 유입 검색어를 보고 제목/소제목 보강 제안.

## 글 구조 (네이버 검색/체류 최적화)
> 아래 서식은 기본값입니다. 취향에 맞게 바꾸세요. (예: 목차 생략, 한 줄 요약 사용)
1. 제목 후보 3개 (30자 내외, 키워드 앞배치, 낚시성 금지)
2. **목차**: 본문 맨 앞(제목 바로 아래)에 `**📑 목차**`(라벨에만 이모지) + `1. ` 번호 목록(불렛 `-` 금지)으로 `##` 소제목을 순서대로 나열.
3. 도입: 공감/문제 제기 2~3문장
4. 본문: `##` 소제목 3~5개, 문단은 2~3문장으로 짧게, 필요시 목록/인용
5. 마무리: 그 글의 핵심 결론이나 조건을 짚는 1~3문장 + 글에 맞는 댓글 유도. **마무리 멘트는 글마다 다르게 쓴다.** "참고가 되길 바란다", "궁금한 점은 댓글로 남겨주면 아는 만큼 답해보겠다" 같은 고정 문구를 여러 글에 반복하지 않는다.
6. 이미지 위치는 `[사진: 설명 (파일명)]`, 영상 위치는 `[영상: 설명]` 형태로 표시. 사진 파일이 있으면 파일명을 괄호로 적어 `pnpm fill --photos <폴더>` 로 자동 삽입. 제품 후기는 언박싱·사용 장면 등 영상이 효과적인 곳에 `[영상:]` 제안
7. 해시태그 8~20개: 본문 맨 마지막 줄에 `#태그1 #태그2 …` 형식(공백 구분, 콤마 금지). `copy_html.py` 가 이 줄을 11px 로 변환한다.

## 사실성
- 수치/가격/날짜/제품 스펙 등 검증 필요한 내용은 WebSearch 로 확인. 확인 못 한 건 쓰지 말고 `[확인 필요: …]` 로 표시.
- 실제 경험이 필요한 후기류는 사용자가 준 정보만 사용. 경험을 지어내지 말고 `[내 경험 추가: …]` 자리표시자를 남긴다.
- 협찬/광고 글이면 말미에 협찬 표기 문구 자리를 둔다.

## 가독성 서식 (copy_html.py 지원 문법)
- **정보 항목(주소·이용 방법·전화·영업시간·휴무 등)**: 불렛 대신 항목 앞에 이모지를 붙인 줄. 예) `📍 주소: …` `📞 전화: …` `⏰ 영업시간: …` `🚫 휴무: …`
- **지도**: 가게·장소가 있는 글(맛집·카페·숙소 등)은 정보 섹션 바로 아래에 `[지도: 상호]` 를 **단독 문단**으로 둔다. `pnpm fill` 이 에디터의 '장소' 컴포넌트로 바꿔 넣는다. (특정 장소가 없는 서비스 글은 제외)
- **사진 설명(캡션)**: `[사진: 설명 (파일명)]` 의 설명이 사진 설명으로 입력된다. 사진에 실제로 보이는 내용만 적는다.
- **역할 구분(SEO)**: 소제목 / 요약 인용구 / 본문을 서식으로 나눈다.
  - 소제목(`##`) = 24px 굵게 + 버티컬라인 인용구(인용구 2). (`pnpm fill` 기본 동작, 끄려면 `--no-quote-headings`)
  - 요약 인용구(`> 총평`) = 기본 인용구(인용구 1). 소제목과 같은 스타일 금지
  - 소소제목(`###`) = 19px 굵게 일반 문단, 본문 = 일반 텍스트
- `==핵심 문구==` 노란 형광펜 (글당 4~6곳, 수치·결론·핵심 행동 위주로 과용 금지)
- `**굵게**`, `- 목록`, `> 인용`, `[텍스트](URL)` 링크
- 문단은 2~3문장, 한 문단 한 생각. 문단 사이 여백은 자동.
- `[사진:]`·`[영상:]`·`[지도:]`(파란 배경, 직접/자동으로 넣을 자리), `[내 경험 추가:]`·`[확인 필요:]`(빨간 배경)은 자동 하이라이트되어 채울 곳이 눈에 띔

## 노출 팁 (비공식 — 블로그/마케팅 매체 공통 의견 정리, 네이버 공식 기준 아님)
- **직접 경험이 핵심**: 경험 없는 자동 생성·광고성 도배글은 저품질로 판별될 수 있다는 의견이 많다. `[내 경험 추가]` 는 반드시 본인 경험으로 채우고, 채우기 문장·상투구는 지운다. 초안을 그대로 발행하지 않도록 안내.
- **사진은 직접 촬영본**, 핵심 정보는 사진 속이 아니라 텍스트로도 적는다. 사진 설명/대체텍스트 입력 권장.
- **제목**: 검색 의도에 맞춘 핵심 키워드를 앞쪽에. 낚시성·과장 금지.
- **키워드 반복 금지**: 같은 키워드를 억지로 반복(키워드 스터핑)하면 저품질 신호. 자연스럽게 제목·첫 문단·소제목 1~2곳·마무리.
- **구조화**: 소제목, 목록, 필요하면 비교표/체크리스트. 분량은 정보량이 충분할 때 2,000자 안팎.
- **복사·짜깁기 금지**: 다른 글/공식 문구를 그대로 가져오지 말고 직접 쓴 표현으로.
- **사실 검증**: 가격·약관·지역은 확인 후 기재, 확인 불가 시 `[확인 필요]`.
- 블로그 운영 조언(응답 끝에 한 줄만, 필요할 때): 한 주제에 집중해 꾸준히 발행, 하루 다수 발행 같은 대량 패턴은 피하기, 발행 후 제목을 검색해 노출 확인.

## 초대/제휴 링크 (협찬·대가 표기)
- 초대 링크·추천인 코드·제휴 링크에 보상이 있으면 글에 경제적 이해관계 표기 필수(예: "이 링크로 가입하면 나에게도 소정의 혜택이 제공된다"). 보상 여부는 사용자가 확인, 모르면 `[확인 필요]`.
- 링크는 사용자가 준 URL 만 사용하고 지어내지 않는다. URL 미제공 시 `[링크: …]` 자리표시자. 제공되면 `[텍스트](URL)` 로 넣는다.
- 기존 글을 내부 링크로 연결할 땐 RSS(`https://rss.blog.naver.com/{{BLOG_ID}}.xml`)에서 실제 링크를 찾는다 (WebFetch 가 막혀 있으면 `curl -sL` 사용).

## 출력
1. `posts/YYYY-MM-DD-<slug>.md` (레포 루트 기준) 에 저장 (첫 줄 `# 선택한 제목`, 제목 후보는 응답에 표시)
2. 에디터 입력: `curl -s http://127.0.0.1:${CHROME_DEBUG_PORT:-9222}/json/version` 으로 디버깅 크롬 확인 → 없으면 `pnpm chrome` 실행 후 사용자에게 네이버 로그인 요청(QR/일회용 번호). 로그인돼 있으면 `pnpm fill posts/<파일>.md [--photos <사진폴더>]` 로 제목·본문(·사진·지도) 입력 (발행 버튼은 절대 누르지 않음). 디버깅 크롬을 쓸 수 없으면 `python3 -I scripts/copy_html.py <파일>` 로 본문만 클립보드에 복사하고 제목은 응답에 표시
3. 응답에는 제목 후보 3개 + 파일 경로 + 남은 `[사진:]`/`[확인 필요]`/`[내 경험 추가]` 개수 + 발행 전 체크 3줄(직접 찍은 사진 삽입·경험 채우기·사실 확인)만 간단히. 본문 재출력 금지.

> 제목은 에디터 제목란에 입력된다. 스크립트가 첫 `# ` 제목 줄을 제외하고 본문만 복사한다.
